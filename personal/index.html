01

起点 / ORIGIN

一切，从一辆车开始。

大学时，我在广告学工作室参与一汽-大众探歌的品牌年轻化策划。面对一台车，我开始思考：产品的技术特点，怎样才能变成年轻人愿意了解的内容？

从洞察、创意到视觉表达，广告学让我学会组织信息，也让我逐渐找到自己感兴趣的方向：让有技术含量的产品，被更多人理解。学院奖策划实践中，力诚蟹棒方案获铜奖，江中与云南白药方案获优秀奖。

02

验证 / PROOF

把技术，翻译成人话。

在京东方艺云，我参与小课屏新品上市传播，撰写与协同发布内容：50 篇稿件、30 万+阅读曝光、80 家媒体渠道，GEO 优化让搜索曝光提升约 40%。在这里学会第一课：量产内容，但不稀释质量。

然后是理想汽车，我真正钻进了技术里。协同研发与产品团队梳理技术信息，把 VLM 智驾、自研芯片、线控底盘写成 C 端用户愿意看的内容；跑车展，上 L8、L9 发布会和家庭科技日的传播一线；顺手用 Claude Code 写了个 Python 脚本，给自己搭了一块竞品内容监测看板。

广告学教会我表达。
理想教会我——表达之前，先搞懂技术本身。

03

深入 / DEPTH

走进赛道的正中央。

在松延动力品牌公关部，我开始参与人形机器人行业的传播。WAIC、WRC、世界人形机器人运动会——媒体邀约、采访 QA、现场传播、会后沉淀，这些活动成为了具体的工作场景。

我也参与创始人 IP 的选题、内容框架和稿件打磨；围绕运控技术、世界模型、Agent 等方向，整理信息并撰写通稿与公众号内容。

这个行业不缺技术，
缺的是把技术讲明白的人。我想干这个。

思考 / THINKING

工作之外，我刷得最多的是晚点LatePost、36氪、数字生命卡兹克这类科技媒体。看得多了，慢慢长出自己的判断——

机器人品牌做到最后，
拼的是让人放心。

/ 01

让最难的技术，拿到应得的传播分

如果一个演示的难点没有被解释，观众就很难判断它的价值。我希望从任务、环境和失败条件讲起，用对比与过程说明“难在哪里”，再让观众理解技术进步意味着什么。

/ 02

少讲参数，多讲画面

写技术内容时，我会继续追问：这个参数改善了谁的体验？在什么条件下成立？把性能放回场景，说明能解决的问题与适用边界，表达才更有说服力。

/ 03

选择一个能被体验的能力入口

我关注 AI 品牌怎样把宽泛的能力变成用户能够上手的体验。比如 Coding：生成结果、修改过程和实际效果都更容易被看见。我想把这套思路带进技术传播，让产品、品牌与内容围绕可验证的任务共同打磨表达。

05

从内容与视觉表达，到账号运营与项目协同，这是我持续积累的五个方向。

大型项目执行 参与车展、L8/L9 发布会、家庭科技日及 WAIC、WRC、机器人运动会相关传播，推进媒体沟通、QA、物料和发布跟进。
趋势洞察 · 品牌判断 日常关注晚点、36氪、数字生命卡兹克等科技内容，结合行业观察与工作反馈，持续打磨自己的选题判断。

我不想只做"发稿的人"。
我想把技术理解、内容表达和项目执行连起来。
